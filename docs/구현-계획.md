# 카페 주문 배포·시트 연동 실습

## 요청과 성공 기준
- 추가 요청: 외부 DB·서버·배포 계정과 연결되지 않은 ZIP을 배포한다. 압축을 푼 최상위 폴더에서 Codex에 ‘로컬로 연결해봐’라고 요청하면 설치·키 입력 없이 로컬 화면과 체험 주문까지 실행한다.
- 로컬 실행은 .env 파일과 외부 연결 환경 변수를 사용하지 않는다. Google 연결은 이후 연수생이 Vercel에서 직접 설정할 때만 활성화한다.
- 바탕화면에 ZIP을 새로 풀고 별도 Codex 세션에서 실행하여 배포본 자체를 확인한다.
- 연수생이 ZIP을 풀어 GitHub에 올리고 Vercel에 배포한다.
- 실제 카페의 네이버 지도 링크에서 매장을 확인하고, 실습 화면에서 메뉴를 담아 주문한다.
- Google Sheets API를 연결하면 주문 한 건을 시트 한 행에 기록한다. 연결 전에는 체험 주문임을 구분한다.
- 매장으로 실제 주문을 전달하거나 결제하지 않는다. 사용자 이름 대신 연수용 별칭만 받는다.
- 인증키는 서버 환경 변수로만 사용하고 ZIP·GitHub·브라우저에 포함하지 않는다.

## 기존 자료와 디자인 근거
- 현재 상위 폴더는 Git 저장소가 아니다. 이번 파일만 별도 폴더에 만들고 Git 초기화·원격 생성·배포는 하지 않는다.
- 상위 폴더에 적용할 AGENTS.md·Design.md·Soul.md가 없음을 확인했다.
- 참고 사이트에서 카페 선택, 메뉴 목록, 가격, 주문 확인 흐름과 따뜻한 바탕·녹색 선택 상태를 확인했다.
- 목적·대상·핵심 행동은 현재 요청으로 확인했다. 톤과 화면 밀도는 제공된 참고 화면을 근거로 한다.
- 개인 기준 라우터는 unavailable을 반환했다. 후보 기준은 적용하지 않고 현재 요청과 공통 지침을 따른다.

## 구현 선택
- 프레임워크·외부 런타임 의존성이 없는 HTML/CSS/JS와 Vercel Node.js Functions를 사용한다.
- public/에는 공개 파일만, api/에는 서버 진입점만, lib/에는 검증·시트 인증 코드를 둔다.
- Google 서비스 계정으로 서버에서 OAuth 토큰을 발급받고 Sheets values.append를 호출한다.
- 가격·메뉴·옵션은 서버의 동일한 카탈로그로 검증한다. 클라이언트가 보낸 합계는 신뢰하지 않는다.
- Google 설정이 일부만 있거나 저장이 실패하면 체험 성공으로 바꾸지 않는다.
- 주문 전송 중 중복 클릭을 막고 재시도 때 주문 ID를 유지한다. Sheets에는 원자적 고유 키 제약이 없으므로 동시 요청의 정확한 1회 저장은 보장하지 않는다고 문서화한다.
- 실습 코드(선택)를 입력받아 공개 배포의 무작위 쓰기를 줄인다. 실제 서비스용 인증으로 설명하지 않는다.
- 초기 실습은 배포 10~15분, Sheets 연결은 별도 20~30분을 목표로 안내한다. Google Cloud 계정 정책에 따라 더 걸릴 수 있다.

## 화면과 상태
- 데스크톱: 매장 정보·메뉴 목록 왼쪽, 주문 내역 오른쪽. 모바일: 한 열과 하단 주문 내역 이동 버튼.
- 검색, 분류, 온도 선택, 수량, 별칭, 실습 코드, 최종 제출, 완료 영수증.
- 메뉴 없음·장바구니 비어 있음·로딩·서버 연결 오류·시트 저장 오류·체험 완료·시트 저장 완료를 구분한다.
- 녹색 계열의 단일 강조색, 크림색 참조 바탕, 17px 본문, 44px 이상의 주요 조작 영역, 명확한 포커스.
- 매장명과 네이버 링크는 실제 자료를 사용한다. 가격·선정 메뉴는 실습용 예시임을 화면과 출처 문서에 명시한다.

## 검증 및 산출물
- Node 기본 테스트로 가격 위조, 입력 검증, 인증, Sheets 요청, 실패 응답을 검증한다.
- 로컬 서버에서 주문·완료·검색·빈 상태·잘못된 실습 코드·좁은 화면을 확인한다.
- 목표 시안과 실제 화면을 비교하고 근거를 docs/검증-기록.md에 남긴다.
- 최종 ZIP에는 소스·기본 메뉴·환경 변수 예시·시트 머리글 CSV·한국어 안내서를 포함한다.
- work/의 재생성 가능한 파일과 테스트 출력은 최종 ZIP에서 제외한다.

## 실제 메뉴 사진 포함 요청
- 실제 메뉴 사진 8장을 참고 앱에서 확인해 public/images에 포함한다. 원본 주소와 원본 상품명을 출처 문서에 기록한다.
- 사진은 원본 4:3 비율로 표시하며 외부 이미지 서버를 직접 호출하지 않는다.
- 음료 7종의 이름·예시 가격과 주문·시트 코드는 유지한다. 초코 쿠키 원본이 없어 실제 사진이 있는 임자떡 쿠키로 디저트의 이름·설명만 맞춘다. 사용자도 임자떡 쿠키로 변경하도록 답변했다.
- 사진 추가 후 PC·모바일과 주문 완료를 다시 확인한다.
