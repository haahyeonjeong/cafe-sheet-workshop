# 데이터 출처와 표시 범위

- 기준일: 2026-10-26(한국 시간).
- 사용자가 제공한 참고 앱: https://naver-kiosk-menu.vercel.app/ . 실제 화면에서 읍천리382 오산1호점과 경기 오산시 경기대로 209 1층 104호 주소, 카페·메뉴·주문 흐름을 확인했다.
- 네이버 지도: https://map.naver.com/p/search/%EC%9D%8D%EC%B2%9C%EB%A6%AC382%20%EC%98%A4%EC%82%B01%ED%98%B8%EC%A0%90 . 실제 검색 화면에서 해당 카페 검색 결과를 확인했다.
- 메뉴 8종·설명·가격은 API·배포 연습을 위해 단순화한 예시 데이터이다. 매장의 현재 공식 메뉴·가격으로 검증한 자료가 아니다. 앱 안에 예시임을 표시했다.
- 네이버 검색·지도 API 키를 요구하지 않으며, 검색 링크를 새 탭으로 여는 방식이다. 매장 정보를 실시간 수집하거나 주문을 매장에 전송하지 않는다.
- 사용자의 실제 메뉴 사진 포함 요청에 따라 참고 앱의 메뉴 이미지 원본을 가져와 public/images에 포함했다. 사진마다 원본 메뉴명과 원본 URL을 아래에 기록한다. 외부 이미지 주소를 직접 연결하지 않으므로 배포 후 앱은 같은 프로젝트 안의 파일을 읽는다. 사진의 권리가 제작자에게 이전된다고 표시하지 않는다. 리뷰·후기·웹폰트·외부 자바스크립트는 포함하지 않는다.
- Google Sheets API의 행 추가와 서비스 계정 인증은 아래 공식 문서를 확인했다.
  - https://developers.google.com/identity/protocols/oauth2/service-account
  - https://developers.google.com/workspace/guides/create-credentials
  - https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/append
  - https://developers.google.com/workspace/sheets/api/limits
- 배포 안내 근거:
  - https://vercel.com/docs/git
  - https://vercel.com/docs/functions/runtimes/node-js
  - https://vercel.com/docs/builds/configure-a-build
  - https://vercel.com/docs/environment-variables
